# 🩺 סימולטור ועדה רפואית · ביטוח לאומי

אתר שבו אדם מזין את הדוח הרפואי שלו מהמוסד לביטוח לאומי, ורופא AI ("ד״ר אבי")
מראיין אותו בדיוק כמו בוועדה הרפואית האמיתית. בסוף השיחה המשתמש מקבל:

- **הערכת אחוזי הנכות** הצפויים (לפי סעיפי הליקוי ברשימת הליקויים).
- **הקצבה הצפויה** (הבחנה בין נכות כללית לנכות מעבודה).
- **טיפים פרקטיים** מה לעשות ומה לומר בוועדה כדי לקבל את המגיע (בכנות, בלי הגזמות).

> ⚠️ **הבהרה:** השירות נותן הערכה בלבד, אינו מהווה ייעוץ רפואי/משפטי ואינו תחליף
> לוועדה הרשמית. מומלץ להיוועץ בעורך דין או בארגון זכויות לפני הגשה.

## איך זה עובד

הלקוח (דפדפן) מנהל שיחת צ'אט מול שרת Node/Express קטן. השרת מוסיף את ה-Prompt
המערכתי (דמות רופא הוועדה) ופונה ל-Claude API. מפתח ה-API נשמר בצד השרת בלבד
ולא נחשף לדפדפן.

```
דפדפן (public/) ⇄ Express (server.js) ⇄ Claude API
```

## התקנה והרצה

דרישות: Node.js 18 ומעלה, ומפתח API של Anthropic.

```bash
cd committee-assistant
npm install

# הגדרת משתני סביבה
cp .env.example .env
# פתחו את .env והכניסו את ANTHROPIC_API_KEY שלכם

npm start
```

ואז פתחו בדפדפן: <http://localhost:3000>

### משתני סביבה

| משתנה | תיאור | ברירת מחדל |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | מפתח ה-API (חובה) | – |
| `CLAUDE_MODEL` | מודל Claude | `claude-sonnet-4-6` |
| `PORT` | פורט השרת | `3000` |

## מבנה הפרויקט

```
committee-assistant/
├── server.js          # שרת Express + אינטגרציה ל-Claude + ה-Prompt המערכתי
├── package.json
├── .env.example
└── public/
    ├── index.html     # מסך פתיחה (הזנת דוח) + מסך צ'אט
    ├── styles.css     # עיצוב RTL בעברית
    └── app.js         # לוגיקת הצ'אט בצד הלקוח
```

## הערות פיתוח

- ניתן להחליף מודל דרך `CLAUDE_MODEL` (למשל `claude-opus-4-8` להערכה איכותית יותר,
  או `claude-haiku-4-5-20251001` למהירות וחיסכון).
- ה-Prompt המערכתי נמצא ב-`server.js` תחת `SYSTEM_PROMPT` – שם אפשר לחדד את
  התנהגות הרופא, השאלות, ופורמט הסיכום.
- הסיכום הסופי מסומן על ידי המחרוזת `===הערכה סופית===` בתחילת ההודעה, והלקוח
  מעצב אותו בכרטיס מודגש.
